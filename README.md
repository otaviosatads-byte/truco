# 🃏 Truco em C

Jogo de Truco desenvolvido em linguagem C, como projeto acadêmico para praticar lógica de programação e implementar a dinâmica de um jogo de cartas.

O projeto utiliza uma interface interativa pelo terminal e estruturas de dados para organizar as cartas e as informações das partidas.

## 🎮 Sobre o projeto

A aplicação busca reproduzir a dinâmica do Truco, trabalhando a organização das cartas, o gerenciamento das rodadas e a aplicação das regras do jogo.

## 🛠️ Tecnologias e conceitos

- Linguagem C
- Lógica de Programação
- Vetores
- Estruturas condicionais e de repetição
- Modularização com funções
- Manipulação de dados
- Resolução de problemas

## ▶️ Como executar

**1. Clone o repositório:**

```bash
git clone URL_DO_REPOSITORIO
```

**2. Entre na pasta do projeto.**

**3. Compile utilizando GCC:**

```bash
gcc *.c -o truco
```

**4. Execute o programa:**

Windows:

```bash
.\truco.exe
```

Linux:

```bash
./truco
```

## 🎯 Objetivo

Consolidar conhecimentos da linguagem C por meio da implementação de um jogo de cartas, desenvolvendo raciocínio lógico, organização de código e capacidade de resolução de problemas.
